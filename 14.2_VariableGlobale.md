### 🔥 **Les Variables Superglobales en PHP : Détails Approfondis**  

Les variables **superglobales** sont des tableaux associatifs intégrés en PHP, accessibles partout dans le script. Elles permettent de manipuler des **données utilisateur**, des **sessions**, des **fichiers**, et des **informations serveur**.  

---

# ✅ **1. `$_REQUEST` : Mélange GET, POST et COOKIE**  

### **📌 Définition :**  
`$_REQUEST` regroupe les valeurs envoyées via `$_GET`, `$_POST` et `$_COOKIE`. Cela permet d’accéder aux données sans se soucier de la méthode d’envoi.  

### **⚠️ Attention : Sécurité et Limites**
- Mélanger `$_GET`, `$_POST` et `$_COOKIE` peut **causer des conflits** si une même clé est définie dans plusieurs.
- **Ne pas l’utiliser pour des données sensibles** car un attaquant peut injecter des valeurs via les cookies.  

### **✅ Exemple :**
```php
// URL : http://mon-site.com/page.php?nom=Tom
$_COOKIE["nom"] = "Alice";
$_POST["nom"] = "Bob";

echo $_REQUEST["nom"]; // Priorité selon l'ordre : POST > GET > COOKIE
```
**Résultat :** `Bob` (POST a la priorité)  

---

# ✅ **2. `$_SESSION` : Stocker des Données Temporaires par Utilisateur**  

### **📌 Définition :**  
Les **sessions** permettent de **mémoriser des informations** sur un utilisateur tant qu’il navigue sur le site. Contrairement aux **cookies**, elles sont stockées sur le **serveur** et **non sur le navigateur**.  

### **🔹 Différences avec un Cookie :**
| Critère        | `$_SESSION` | `$_COOKIE` |
|---------------|------------|------------|
| Stockage      | Serveur    | Navigateur (client) |
| Sécurité      | Plus sécurisé | Moins sécurisé (modifiable côté client) |
| Durée         | Expire quand l’utilisateur ferme le navigateur (par défaut) | Expire selon la durée définie |
| Taille max    | Illimité   | 4 Ko environ |

### **🔑 Ouverture et Fermeture de Session**
Avant d’utiliser `$_SESSION`, il faut **démarrer la session** avec `session_start();`.  

```php
<?php
session_start(); // Démarrer une session
$_SESSION["utilisateur"] = "Alice"; // Stocker une valeur

echo "Bienvenue, " . $_SESSION["utilisateur"]; // Affiche "Bienvenue, Alice"
?>
```

### **🛑 Détruire une Session :**
```php
session_start();
session_destroy(); // Supprime TOUTES les données de session
unset($_SESSION["utilisateur"]); // Supprime UNE donnée spécifique
```

# ✅ **3. `$_COOKIE` : Stocker des Données sur le Navigateur**  

### **📌 Définition :**  
Un **cookie** permet de **stocker des informations** sur le navigateur de l’utilisateur et de les **récupérer lors des visites suivantes**.  

### **📌 Création d’un Cookie :**
```php
setcookie("utilisateur", "Alice", time() + 3600, "/"); 
// Stocke "Alice" pendant 1 heure (3600 sec) sur tout le site "/"
```
**Arguments de `setcookie()` :**  
1. **Nom du cookie**
2. **Valeur**
3. **Expiration (timestamp Unix)**
4. **Chemin (définit sur quelles pages il est accessible)**  

### **📌 Récupération d’un Cookie**
```php
echo "Bonjour, " . $_COOKIE["utilisateur"];
```

### **📌 Suppression d’un Cookie**
```php
setcookie("utilisateur", "", time() - 3600); // Expire immédiatement
```

### **🚨 Problème de Sécurité :**
- Les cookies peuvent être **modifiés par l’utilisateur** → **Ne jamais stocker de données sensibles !**
- Utiliser **`httponly` et `secure`** pour éviter des failles XSS et de transmission en HTTP.  
```php
setcookie("securise", "valeur", time() + 3600, "/", "", true, true); 
// "true, true" = Secure et HttpOnly
```

# ✅ **4. `$_FILES` : Gestion des Fichiers Uploadés**  

### **📌 Définition :**  
Permet d’envoyer des **fichiers** via un formulaire HTML.  

### **📌 Formulaire HTML :**
```html
<form action="upload.php" method="POST" enctype="multipart/form-data">
    <input type="file" name="monFichier">
    <button type="submit">Envoyer</button>
</form>
```

### **📌 Récupération et Traitement en PHP (`upload.php`)**
```php
<?php
if ($_FILES["monFichier"]["error"] == UPLOAD_ERR_OK) {
    $nom_temporaire = $_FILES["monFichier"]["tmp_name"];
    $nom_fichier = basename($_FILES["monFichier"]["name"]);
    move_uploaded_file($nom_temporaire, "uploads/" . $nom_fichier);
    echo "Fichier téléchargé avec succès !";
} else {
    echo "Erreur lors de l'upload.";
}
?>
```
### **📌 Vérifications de Sécurité**
✅ **Limiter la taille** du fichier :
```php
if ($_FILES["monFichier"]["size"] > 2000000) { // 2 Mo max
    die("Fichier trop volumineux !");
}
```
✅ **Limiter les extensions** autorisées :
```php
$types_valides = ["image/jpeg", "image/png", "application/pdf"];
if (!in_array($_FILES["monFichier"]["type"], $types_valides)) {
    die("Type de fichier non autorisé !");
}
```

# ✅ **5. `$_SERVER` : Informations Serveur & Requête**  

### **📌 Définition :**  
`$_SERVER` stocke des **informations sur l’environnement serveur** et la requête **HTTP**.  

### **📌 Quelques Valeurs Utiles**
| Clé | Description |
|------------------|-----------------------------|
| `$_SERVER['REQUEST_METHOD']` | Type de requête (GET, POST...) |
| `$_SERVER['REMOTE_ADDR']` | Adresse IP du visiteur |
| `$_SERVER['HTTP_USER_AGENT']` | Navigateur de l’utilisateur |
| `$_SERVER['REQUEST_URI']` | URL demandée |
| `$_SERVER['SCRIPT_NAME']` | Nom du fichier exécuté |
| `$_SERVER['HTTP_REFERER']` | URL de la page précédente |

### **📌 Exemples**
```php
echo "Votre IP : " . $_SERVER['REMOTE_ADDR'];
echo "<br>Vous utilisez : " . $_SERVER['HTTP_USER_AGENT'];
echo "<br>Page actuelle : " . $_SERVER['REQUEST_URI'];
```

---

# ✅ **📌 Récapitulatif : Différences Clés**  

| Variable | Stockage | Durée | Sécurité | Usage |
|----------|---------|------|---------|------|
| `$_SESSION` | Serveur | Fin de session | Sécurisé | Stocker les données utilisateur |
| `$_COOKIE` | Navigateur | Définie (ex. 1 jour) | Moins sécurisé | Sauvegarder les préférences |
| `$_FILES` | Serveur (temporaire) | Jusqu’au traitement | Vérification requise | Upload de fichiers |
| `$_SERVER` | Serveur | Toujours disponible | Peu de risques | Infos serveur et requêtes |
