### **1. Introduction aux Tableaux en PHP**
Un **tableau** est une structure de données qui permet de stocker plusieurs valeurs dans une seule variable. PHP prend en charge **trois types principaux de tableaux** :  
1. **Tableaux indexés** (clés numériques)  
2. **Tableaux associatifs** (clés personnalisées)  
3. **Tableaux multidimensionnels** (tableaux imbriqués)

---

## **2. Tableaux Indexés**
Un **tableau indexé** utilise des **indices numériques** pour référencer ses éléments.

### **📌 Déclaration d’un tableau indexé**
```php
$fruits = ["Pomme", "Banane", "Cerise"];
```
Ou avec `array()`, qui était plus courant avant PHP 5.4 :
```php
$fruits = array("Pomme", "Banane", "Cerise");
```

### **📌 Accès aux éléments**
```php
echo $fruits[0]; // Affiche "Pomme"
```

### **📌 Ajouter un élément**
```php
$fruits[] = "Mangue"; // Ajoute à la fin du tableau
array_push($fruits, "Orange", "Fraise"); // Ajoute plusieurs éléments
```

### **📌 Modifier un élément**
```php
$fruits[1] = "Ananas"; // Remplace "Banane" par "Ananas"
```

### **📌 Supprimer un élément**
```php
unset($fruits[2]); // Supprime "Cerise"
$fruits = array_values($fruits); // Réindexer le tableau
```

### **📌 Compter les éléments**
```php
echo count($fruits); // Retourne le nombre d'éléments
```

---

## **3. Tableaux Associatifs**
Un **tableau associatif** utilise des **clés personnalisées** au lieu d'indices numériques.

### **📌 Déclaration**
```php
$personne = [
    "nom" => "Alice",
    "age" => 25,
    "ville" => "Paris"
];
```

### **📌 Accès aux éléments**
```php
echo $personne["nom"]; // Affiche "Alice"
```

### **📌 Ajouter / Modifier un élément**
```php
$personne["profession"] = "Développeuse";
$personne["age"] = 26;
```

### **📌 Supprimer un élément**
```php
unset($personne["ville"]); // Supprime "ville"
```

---

## **4. Tableaux Multidimensionnels**
Un **tableau multidimensionnel** est un tableau contenant d'autres tableaux.

### **📌 Exemple**
```php
$eleves = [
    ["nom" => "Alice", "age" => 18],
    ["nom" => "Bob", "age" => 20],
    ["nom" => "Charlie", "age" => 19]
];
```

### **📌 Accès aux données**
```php
echo $eleves[0]["nom"]; // Affiche "Alice"
```

### **📌 Boucler sur un tableau multidimensionnel**
```php
foreach ($eleves as $eleve) {
    echo $eleve["nom"] . " a " . $eleve["age"] . " ans.<br>";
}
```

---

## **5. Les Méthodes les Plus Utilisées**
PHP propose de nombreuses **fonctions pour manipuler les tableaux**.

### **📌 Vérifier si une clé existe (`array_key_exists`)**
```php
if (array_key_exists("age", $personne)) {
    echo "L'âge est défini.";
}
```

### **📌 Vérifier si une valeur existe (`in_array`)**
```php
if (in_array("Pomme", $fruits)) {
    echo "Pomme est dans le tableau.";
}
```

### **📌 Récupérer toutes les clés (`array_keys`)**
```php
$cles = array_keys($personne);
print_r($cles); // Affiche ["nom", "age", "profession"]
```

### **📌 Récupérer toutes les valeurs (`array_values`)**
```php
$valeurs = array_values($personne);
print_r($valeurs); // Affiche ["Alice", 26, "Développeuse"]
```

### **📌 Trier un tableau**
```php
sort($fruits); // Trie les valeurs croissantes (indexé)
asort($personne); // Trie par valeurs (associatif)
ksort($personne); // Trie par clés (associatif)
```

2. Ajoute un nouveau pays.
3. Supprime le troisième pays.
4. Trie le tableau par ordre alphabétique.
5. Affiche la liste des pays après chaque modification.

3. Affiche toutes les informations du film avec une boucle `foreach`.
