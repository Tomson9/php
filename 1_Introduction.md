## 1️⃣ *** Introduction ***

Bonjour,
Dans ce cours, on vous apprendrez tout ce que vous devez savoir pour commencer à écrire du PHP. Si vous cherchez à construire un super site web évolutif et facilement maintenable ou application web, avec PHP vous pouvez le faire.  PHP est génial parce qu'il s'intègre super bien avec HTML.  Donc, vous pouvez en fait écrire votre code PHP en même temps que le HTML et ils travaillent parfaitement ensemble.  Il y a des millions de sites web et d'applications web qui sont actuellement en ligne, qui utilisent PHP et compte sur PHP côté serveur. Et PHP est ce que
nous appellerions un langage côté serveur. Donc c'est en gros, un langage qui va reposer sur le serveur web, et il pourra interagir avec le client et faire différentes choses afin de rendre votre site web plus puissant.

Dans ce cours, nous allons aborder les bases des bases.  Donc, je vais juste vous apprendre comment fonctionne PHP, nous allons installer PHP et tout configurer puis nous allons créer un premier fichier PHP et voir la manière dont PHP peut interagir avec HTML.  

Dans la partie un peu plus avancé, nous parlerons de comment on peut utiliser PHP pour obtenir des données d'un formulaire HTML. Nous verrons comment PHP peut être utilisé en combinaison avec HTML pour rendre nos sites web plus puissants. Et ensuite, nous allons examiner juste quelques concepts généraux de programmation, des choses comme
les instructions if, et les boucles for, et les tableaux et structure de données.  Donc, nous allons aborder
non seulement comment PHP peut être utilisé sur le web, mais aussi comment PHP peut être utilisé de manière générale
langage de programmation. 
En fin, nous parlerons de la programmation orientée objet. Donc, nous allons voir comment nous pouvons utiliser PHP pour créer des choses comme des classes et des objets. Alors si tout ça te semble bon, alors ce cours a quelque chose pour vous. 

Nous espérons qu'à la fin de ce cours, vous aurez une meilleure compréhension de PHP, et vous vous pourrez commencer à écrire votre propre site web application.
