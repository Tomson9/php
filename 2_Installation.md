## ***Comment installer et configurer PHP sur Windows?***

Donc, PHP est en fait assez facile à installer. Pour configurer. Pour ce faire, nous devons juste télécharger un fichier, et nous allons modifier quelque données sur notre ordinateur Windows,
et ensuite nous devrions pouvoir tout avoir prêt à l'emploi.
La première chose est d'aller sur:
### **Telecharger une version de PHP** 
---
        https://windows.php.net/ -> Downloads -> windows downloads
---
Et vous verrez ici, il y a une option pour un fichier zip: cliquez sur ça.  
Quand télécharger sera terminé, nous allons extraire tous les fichiers.

Après on copie le path pour le mettre dans les variables d'environnement. 
### **Vérifier la version de PHP**  
Si c'est bien fait, ouvrez votre invite de commande et dans le terminal tapez:  

```sh
php -v
```
Si vous voyez la version de PHP s'afficher, c'est bon ! 🎉  
Sinon, il faudra revoir la configuration.
