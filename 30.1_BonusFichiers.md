### 📂 **Manipulation des fichiers CSV, JSON et XML en PHP**  

PHP permet de gérer plusieurs formats de fichiers pour **stocker et échanger des données**. Les plus utilisés sont :  
- **CSV** : Stockage structuré sous forme de tableau (idéal pour importer/exporter des données).  
- **JSON** : Format léger et compatible avec JavaScript (souvent utilisé pour les API).  
- **XML** : Format plus structuré et hiérarchisé (souvent utilisé pour les configurations).  

---

## **📌 1. Manipulation des fichiers CSV en PHP**  
Le **CSV (Comma-Separated Values)** est un format de fichier où les valeurs sont séparées par des virgules (ou des points-virgules `;`).  

### **📖 Lire un fichier CSV**
On utilise `fgetcsv()` pour lire un fichier ligne par ligne.  
```php
<?php
$fichier = fopen("data.csv", "r");

while (($ligne = fgetcsv($fichier, 1000, ",")) !== FALSE) {
    echo "Nom : " . $ligne[0] . " - Age : " . $ligne[1] . "<br>";
}

fclose($fichier);
?>
```
📌 **Explication** :  
- `fgetcsv()` → Lit une ligne et la transforme en **tableau** PHP.  
- `1000` → Nombre maximal de caractères lus.  
- `","` → Délimiteur utilisé (virgule).  

#### **Exemple de fichier `data.csv`**  
```
Jean,25
Alice,30
Marc,28
```

---

### **📝 Écrire dans un fichier CSV**
On utilise `fputcsv()`.  
```php
<?php
$fichier = fopen("data.csv", "a"); // "a" pour ajouter une ligne
$data = ["Paul", 35];

fputcsv($fichier, $data); // Écrit la ligne dans le fichier

fclose($fichier);
?>
```
📌 **Chaque exécution du script ajoutera une ligne.**  

---

## **📌 2. Manipulation des fichiers JSON en PHP**  
Le **JSON (JavaScript Object Notation)** est un format **léger et lisible** souvent utilisé dans les **API REST**.  

### **📖 Lire un fichier JSON**
```php
<?php
$json = file_get_contents("data.json"); // Lire le fichier JSON
$data = json_decode($json, true); // Convertir en tableau associatif

foreach ($data as $personne) {
    echo "Nom : " . $personne["nom"] . " - Age : " . $personne["age"] . "<br>";
}
?>
```
#### **Exemple de fichier `data.json`**  
```json
[
    {"nom": "Jean", "age": 25},
    {"nom": "Alice", "age": 30}
]
```
📌 `json_decode($json, true)` → Convertit le JSON en **tableau associatif**.  

---

### **📝 Écrire dans un fichier JSON**
```php
<?php
$data = [
    ["nom" => "Paul", "age" => 35],
    ["nom" => "Marc", "age" => 28]
];

$json = json_encode($data, JSON_PRETTY_PRINT); // Convertit en JSON formaté
file_put_contents("data.json", $json); // Enregistre dans le fichier
?>
```
📌 `json_encode($data, JSON_PRETTY_PRINT)` → Génère un JSON lisible.

## **📌 3. Manipulation des fichiers XML en PHP**  
Le **XML (Extensible Markup Language)** est un format de stockage structuré.

### **📖 Lire un fichier XML**
```php
<?php
$xml = simplexml_load_file("data.xml");

foreach ($xml->personne as $personne) {
    echo "Nom : " . $personne->nom . " - Age : " . $personne->age . "<br>";
}
?>
```
#### **Exemple de fichier `data.xml`**
```xml
<personnes>
    <personne>
        <nom>Jean</nom>
        <age>25</age>
    </personne>
    <personne>
        <nom>Alice</nom>
        <age>30</age>
    </personne>
</personnes>
```

---

### **📝 Écrire dans un fichier XML**
```php
<?php
$xml = new SimpleXMLElement("<personnes></personnes>");

$personne = $xml->addChild("personne");
$personne->addChild("nom", "Paul");
$personne->addChild("age", "35");

$xml->asXML("data.xml");
?>
```
📌 **Chaque exécution du script ajoutera un nouvel utilisateur.**
